## Summary — lualatex SVG renderer complete

All deliverables landed on this branch and verified via an end-to-end smoke
test (scaffold since removed):

1. `adihtml/adihtml/latex.py` — `Tex(src=None, *, file=None, scale=1.0, alt="")`
   returning `<img src="adihtmltex_{sha3_512}.svg" ...>`.
   - Caller dir resolved via `inspect.stack()[1]` (robust to autobuild's CWD
     trick; the first cut used a helper frame which pointed at the package
     dir — fixed by capturing the frame inside `Tex` itself).
   - Cache: `tex.json` colocated with the calling `.py`, schema
     `{"tex_literals": {hash: ""}, "tex_files": {path: hash}}`. Atomic write
     via `.tmp` + `os.replace`.
   - Compile: temp dir under `/tmp/opencode/latex/<uuid>/`, `lualatex
     -interaction=nonstopmode -halt-on-error`, then `pdf2svg input.pdf
     <dir>/adihtmltex_{h}.svg 1` (page 1). On lualatex failure, raises with
     the `.log` tail.
   - `scale` is caller-applied CSS: emitted as `<img>` width/height from the
     SVG's intrinsic size × scale; not part of the cache key, so re-scaling
     never recompiles.

2. `autobuild.py` — `_DEPS_RE = r"^\s*#DEPS\s+(\S+)\s*$"` (MULTILINE) scans
   each `.py`'s source; paths resolved relative to the `.py`'s dir. Builder
   watches `fName` + all `#DEPS` paths; any mtime change re-runs the build.
   After a rebuild it re-parses `#DEPS` in case new deps appeared. First-build
   pass unchanged.

3. `scripts/clean_latex.py` — `rglob`s `serve/`, deletes every
   `adihtmltex_*.svg` and colocated `tex.json`. Verified: removed 2 SVGs + 1
   tex.json; subsequent `autobuild.py` regenerated them.

4. `.gitignore` — added `adihtmltex_*.svg` and `tex.json`.
