How to Solve Homogeneous Linear Least Squares

Problem setup

Given a matrix A, we want a non-zero vector x that minimizes the homogeneous least-squares objective ||Ax||_2.

Without a constraint, x = 0 minimizes the objective for every matrix A, so the usual problem cannot identify a useful direction. We instead require x to have unit norm.

Success criteria

The post contains a proof of a proposition that identifies the unit-norm minimizer of the homogeneous linear least-squares objective, and includes an unexecuted two-line NumPy example that obtains the SVD solution.

Relevant background

We use the singular value decomposition A = U Sigma V^T, where U and V are orthogonal. Orthogonal matrices preserve the Euclidean norm, so ||Uy||_2 = ||y||_2 and ||Vy||_2 = ||y||_2.
